Place the required VZ200 BIOS ROM files in this directory.

The emulator requires these files to be present:

- VZ200_20.bin — the base VZ200 BIOS ROM
  SHA-256: f6d8ef66df4bb889b43826bbf03a1ec3adff43a1f89acedddcd6657fa944cabc
  MD5:    42c8f9e6c2133ae0e953b89ccbbdb7e2

- VZDOS.VZ — the DOS ROM for the SD Loader target
  SHA-256: 1eb0f5dde1de4ed471969122d998c2096eb31f52847c333380503d6661e4fed7
  MD5:    ada27da11f0cfee73749bea187c15479

Notes:
- The file names must match exactly.
- For the SD Loader target, the DOS ROM must be named VZDOS.VZ.
- On Linux, VZDOS.VZ may be symlinked from the SD folder. On other platforms, copy the file into both locations as needed.
- If you are unsure whether a ROM file is correct, compare its hash to the values above.
